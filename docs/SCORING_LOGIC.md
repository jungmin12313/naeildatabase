# 공공시설물 접근성 진단 점수화 로직 (Scoring Logic)

본 문서는 `naeil` 프로젝트의 접근성 점수 산정 및 통계 로직을 지속적으로 관리하고 기억하기 위해 작성되었습니다.

## 1. 기본 산정 방식 (최신 반영 사항)
* **측정 항목:** 5대 카테고리 (S1_보행로, S2_출입구, S3_화장실, S4_엘리베이터, S5_주차장)
* **결측치(Missing Data) 처리 방식 (2026-09-06 변경):**
  - **규칙:** 특정 시설에 대해 조사가 전무한(데이터가 null인) 카테고리가 있을 경우, **해당 시설에서 조사가 완료된 다른 카테고리들의 "평균 점수"로 결측치를 대체(대입)하여 산정**합니다.
  - **목적:** 특정 카테고리(예: 출입구, 유효폭 등)만 집중적으로 조사한 경우에도, 조사되지 않은 나머지 항목이 0점이나 기본값(50점)으로 처리되어 구역 전체 평균과 레이더 차트 넓이 지수를 왜곡(하락)시키는 현상을 방지하기 위함입니다.
  - **예시:** A 시설의 `S2_출입구` 점수가 90점, `S1_보행로` 점수가 80점이고 나머지가 조사가 안 되었다면, 해당 시설의 평균은 85점이 되며, 조사되지 않은 `S3`, `S4`, `S5` 항목 역시 **자동으로 85점으로 간주**되어 통계 및 차트에 반영됩니다.

## 2. 조사 커버리지 등급제 (Coverage Tier)
* **기준 (`COVERAGE_THRESHOLD`):** 최소 측정 카테고리 개수 (현재 **1개**로 설정됨, `src/config/constants.ts` 참조)
* **정밀진단 (Confirmed):** 측정 항목 수가 `COVERAGE_THRESHOLD` 이상인 시설. (현재 1개 이상이면 무조건 정밀진단으로 간주)
* **예비조사 (Preliminary):** 측정 항목 수가 `COVERAGE_THRESHOLD` 미만인 시설 (현재 기준으로는 0개인 경우만 해당).
* 구역 랭킹 및 주요 통계 데이터는 "정밀진단" 시설들만을 대상으로 계산됩니다.

## 3. 넓이 지수 (Area Index / Final Score) 계산
* 5각형 레이더 차트의 면적을 구하는 공식을 기반으로 계산됩니다.
* 공식: `(s1 * s2 + s2 * s3 + s3 * s4 + s4 * s5 + s5 * s1) / 500`
* 결측치가 평균 점수로 대체되므로, 일부 항목만 조사된 경우에도 조사된 항목들의 평균 점수에 비례하는 정다각형 형태로 넓이 지수가 정상 산출됩니다.

## 4. 로직 적용 범위
위 점수화 로직은 다음의 파일에서 공통적으로 대체(Normalization)되어 적용됩니다:
1. `src/components/Sidebar.tsx` (지도 레이더 차트, 넓이지수, 평균 산정)
2. `src/app/dashboard/page.tsx` (단일 구역 대시보드 통계 및 차트, 엑셀/PDF 출력)
3. `src/app/compare/page.tsx` (다구역 비교 대시보드 차트 및 격차 분석, 엑셀 출력)
